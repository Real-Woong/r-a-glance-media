# r-a-glance-media

Static host for the carousel JPEGs of the `r_a_glance` Instagram channel.
Meta fetches carousel images from public HTTPS JPEG URLs, so the files are
served from GitHub Pages.

Layout: `<output-id>/<content-hash[:12]>/NN.jpg`

Files are generated by `python -m R_A_Glance.src.media prepare` in Project_ContentOps.
Nothing else lives here.
